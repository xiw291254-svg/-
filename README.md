# 📋 回條繳繳通 SlipNotify Pro

> 專為班級導師、活動主辦人與行政人員設計的**「回條繳交情況追蹤與自動催繳短信提醒系統」**。

---

## ✨ 核心特色功能

1. **🚀 點入程式自動跳出催繳提醒 (Auto Reminder Modal)**
   - 每次開啟本系統時，系統自動計算所有回條活動，比對今日日期與截止日。
   - 若有未繳交或已逾期名單，立即跳出**「催繳提醒智能視窗」**。
   - 視窗內可直接一鍵勾選「已收回條」快速核銷，資料即時同步。
   - 智能代入學生姓名、家長稱謂、回條名稱、截止日期與金額等變數。
   - 支援「一鍵複製目前簡訊」、「批量複製每位家長專屬簡訊」、「複製 LINE 群組公告座號格式」。

2. **📁 多回條專案追蹤管理**
   - 支援同時管理多個回條（如：校外教學同意書、流感疫苗接種回條、班費收據確認等）。
   - 每個專案具備完整狀態標籤、剩餘天數倒數、費用註記、繳交率進度條。

3. **👥 學生與成員名單追蹤**
   - 包含欄位：座號、學生姓名、家長稱謂、聯絡電話、繳交狀態、繳交時間、備註。
   - 狀態分類：🟢 已繳交 / 🟡 未繳交 / 🔴 已逾期 / ⚪ 免繳。
   - 點擊狀態標籤即可一鍵切換狀態。
   - 支援關鍵字搜尋（姓名、座號、電話）與狀態篩選標籤。
   - 支援「全選 / 批量勾選」一鍵標記為已繳交、未繳或刪除。

4. **⚡ 批量快速匯入 (Batch Import)**
   - 可直接從 Excel 或通訊錄複製整班資料貼上。
   - 支援多種常見格式（如 `1, 王小明, 王爸爸, 0912345678` 或每行一個姓名自動排座號）。

5. **📱 擬真手機預覽與簡訊發送**
   - 點擊任一位學生成員的簡訊圖示，即可開啟擬真手機聊天畫面。
   - 支援直接點擊 `sms:0912345678?body=...` 連結在手機或筆電簡訊 App 中發送，或點擊 `tel:` 撥號聯繫。

6. **💾 資料持久化與 Excel / CSV 匯出**
   - 本地 `LocalStorage` 自動存檔，重啟瀏覽器不遺失。
   - 支援匯出 Excel 友善之 CSV 報表（含 UTF-8 BOM 中文不亂碼）。
   - 支援完整 JSON 備份檔匯出與還原。
   - 支援一鍵「載入示範資料」隨時重設體驗。

7. **🎨 現代化視覺美學 (UI/UX)**
   - 深色 / 淺色主題自由切換。
   - 質感毛玻璃 (Glassmorphism) 卡片、動態發光警示、流暢操作動畫與 Toast 提示。

## 🚀 如何啟動與使用

### 方法一：直接雙擊開啟（最簡單）
直接在檔案總管中雙擊 `index.html`，即可使用預設瀏覽器（Chrome、Edge 等）開啟使用！

### 方法二：使用內建輕量本機伺服器
在命令列執行：
```bash
python preview_server.py
```
然後在瀏覽器開啟：`http://localhost:8080/index.html`

## 📝 催繳短信模板變數支援

在催繳短信中可使用以下動態替換標籤：
- `{學生姓名}`：自動替換為該學生姓名（如：王小明）
- `{家長姓名}`：自動替換為家長稱謂（如：王爸爸）
- `{回條名稱}`：自動替換為當前回條名稱（如：三年二班 畢業旅行家長同意書）
- `{截止日期}`：自動替換為回條截止日
- `{費用}`：自動替換為回條所需繳交金額
- `{未繳名單}`：自動列出所有尚未繳交同學之座號與姓名
